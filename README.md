# DropEight

Eight-bar live drop desk for bedroom producers and AI-music finishers.

Generators and bedroom sessions often leak the break into the drop at the same height. DropEight writes eight live bars of impact: kick lock, bass floor, crash door, then the ride.

## I/O and MIDI

Because it makes noise, the desk exposes:

- **Audio input** — pick a mic or interface (Web Audio / getUserMedia)
- **Audio output** — pick headphones or interface (setSinkId where the browser allows it)
- **MIDI controller** — Web MIDI input; notes trigger piano chairs, CC1 = bus gain

Chrome / Edge recommended for MIDI + output device selection.
